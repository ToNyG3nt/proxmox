Projet : Projet C#

Apprentissage du C# avec un projet simple.

Description

Ce projet est une simple application console en C# qui demande le nom de l'utilisateur et affiche un message de bienvenue.

Le fichier correspondant est :

  • archives/Informatique/C#/Program.cs

Code source et explications

Voici le code source du programme :


Console.WriteLine("quel est votre nom ?");
string nom = Console.ReadLine();
Console.WriteLine("Bonjour " + nom + "!");

Détails du code :

  • Console.WriteLine("quel est votre nom ?"); : Affiche la question "quel est votre nom ?" dans la console.
  • string nom = Console.ReadLine(); : Lit la ligne de texte entrée par l'utilisateur dans la console et la stocke dans une variable de type chaîne de caractères (string) appelée nom.
  • Console.WriteLine("Bonjour " + nom + "!"); : Affiche un message de bienvenue en concaténant la chaîne "Bonjour ", la valeur de la variable nom, et le caractère "!".
