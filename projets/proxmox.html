Vue d'ensemble

Ce projet est un Home-Lab construit autour d'un Mini-PC basse consommation faisant tourner Proxmox VE. Il héberge plusieurs conteneurs LXC Debian et est exposé publiquement via un tunnel Cloudflare Zero Trust, sans ouverture de port sur la box. L'ensemble est automatisé et géré depuis un Mac via VS Code et Git.

Architecture technique

Hardware

Mini-PC compact Low Power dédié au Home-Lab — silencieux, faible empreinte énergétique.

Économie d'énergie

Extinction automatique chaque soir via une tâche Cron sur le serveur Proxmox, pilotée par planification horaire.

Virtualisation

Proxmox VE avec conteneurs LXC Debian — isolation légère, démarrage rapide, consommation réduite.

Sécurité Zero Trust

Exposition des services via Cloudflare Tunnel — aucun port ouvert sur la box. Accès protégé par OTP.

Workflow DevOps

Push Git depuis VS Code (Mac) — pull automatique déclenché sur le serveur pour déploiement continu sans intervention manuelle.
